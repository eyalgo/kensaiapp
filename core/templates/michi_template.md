# 道 Michi — <instance>'s Way(s)

*The **instance**-level declaration: the endless guiding goal(s) this instance commits to and never
finishes — the bearing the instance steers by. A **declaration**, not a queue (set once; never
worked-and-retired). **1..N** per owner. **No Agari** at instance level (nothing reaches the Michi). The
journey **model** (what Michi / Shukuba / Agari mean) is not here:
`<CORE>/docs/michi_agari.md`. Stamped into `system/michi.md`.*
