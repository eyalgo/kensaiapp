# 根回し Nemawashi — <instance>'s seedbed

*The **instance**-level seedbed: ideas germinating before they're ready to be walked — roots laid before
the road. Sibling to the 道 Michi declaration (`system/michi.md`) and the router 宿場 Shukuba
(`system/shukuba/`), directly under `system/`. Nemawashi exists at both levels — each project has its own
in `journey/` (`<CORE>/doctrine/setup/kensaiapp_structure.md` §2). Like a project's, the instance seedbed has a **pick**: the
candidate pool lives in `unpicked/`, any number at any time; a pick lifts one seed out of it to the
root, alone; an empty root means no idea is active; and, when a seed ripens, it moves to `trail/` —
or to `drop/` when it is killed instead.*

---

**This is a folder, not a file.** Each seed is its own file — `<YYYY-MM-DD>_<slug>.md` — seeded directly
in `system/nemawashi/` as the idea arises. One file per seed, so a closed seed is moved whole; no shared
queue to park or strike through in place.

**Pick one → see only it.** The candidate pool lives in `unpicked/` — any number of ideas, whether or
not one is active. Picking an idea to work now lifts it out of `unpicked/` to the root, alone; no other
candidate moves. The active idea may carry a checklist of the legs it will take — grown as the work
reveals them, not fixed up front. Un-picking an idea puts it back — root → `unpicked/`, leaving the
root empty — by hand today, because no skill performs the pick or the un-pick at this level yet.

**Lifecycle.** **Seed** an early idea as its own file here. When a seed **ripens into work** — a
project, a project Tobiishi, a cross-project effort coordinated by the router `system/shukuba/`, or a
**cut** into the project seeds that will carry it — **move its file to `trail/`** — by hand. When it is **killed** instead — ruled out,
superseded, or abandoned before it was ever picked — **move it to `drop/`** (skill: `nemawashi-drop`).
Never strike a seed through. `system/nemawashi/trail/` is the record of seeds that ripened;
`system/nemawashi/drop/` is the record of the ones we chose not to walk.

**One word, one sense.** *Seed* is how a seed gets here; *drop* is what happens to one that is
killed. A record already in `trail/` or `drop/` may open with a word this seedbed no longer uses —
the folder it sits in is the record, not the wording inside it.
