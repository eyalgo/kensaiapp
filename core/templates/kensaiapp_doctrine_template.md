# <instance> — domain doctrine

*The instance's **general domain doctrine**: the standing rules, vocabulary, and invariants of this
instance's subject area — what every project here inherits. The **fixed-name** instance counterpart to
each project's own `system/projects/<name>/doctrine/<project>_doctrine.md`. `AGENTS.md` § doctrine stubs
points here; stamped verbatim into `system/doctrine/kensaiapp_doctrine.md` — the
name is **fixed**, never inferred from the instance's subject (inferring it produced the
`tracker_doctrine.md` bug).*

---

> **Record here only what binds every project in this instance** — the standing vocabulary, invariants
> and rules of its subject area, which every project inherits without restating them. A rule true of one
> product alone belongs in that project's own domain doctrine
> (`system/projects/<name>/doctrine/<project>_doctrine.md`); putting it here makes every other project
> inherit a rule that is not theirs. Where this file holds nothing, each project's own doctrine is the
> whole of the domain — there is no shared layer above it to consult.
