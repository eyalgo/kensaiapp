# Contributing

Thank you for taking the time. KensaiApp is maintained privately by its author, so this page says
what you can send and what happens to it.

## Issues

Issues are welcome: a problem you hit, or an idea you have. Each one is read. There is no promised
timeline for a fix, and an idea may not be built.

Before you open one, search the [existing issues](https://github.com/eyalgo/kensaiapp/issues?q=is%3Aissue).
Then choose a form: a bug report or a feature request. Remove API keys, tokens and paths on your own
machine from anything you paste.

## Questions

Questions about using KensaiApp, and ideas you want to talk through before they become an issue, go
to [Discussions](https://github.com/eyalgo/kensaiapp/discussions).

## Security

Do not open an issue for a security hole. [SECURITY.md](SECURITY.md) says how to report one
privately.

## Pull requests

Pull requests are not accepted yet. KensaiApp is developed in a private repository, and each release
is cut from it into this one, replacing its files. A pull request merged here would be lost at the
next release.

They will be accepted once KensaiApp is developed in this repository itself. Until then, if you have
a change in mind, open an issue and describe it. A diff in the issue is welcome.
