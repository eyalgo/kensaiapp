# Hint:

Use uv's resolver with version-specific package selections to preserve the baseline transitive
versions without adding constraints to the manifest. The design's generation command is
`uv lock --upgrade-package ast-serialize==0.12.1 --upgrade-package pluggy==1.6.0`.
Leave dependency edges, sources, markers and hashes to uv
(https://docs.astral.sh/uv/concepts/projects/layout/#the-lockfile).
Parse the lock with standard-library `tomllib` and compare a collection of normalized name/version
pairs, checking declaration exactness before splitting. Normalize case and runs of `.`, `_` and
`-` per https://packaging.python.org/en/latest/specifications/name-normalization/#name-normalization.
Keep the reader independent of uv subprocesses. An ordinary `uv run` can update the lock before
running a command (https://docs.astral.sh/uv/concepts/projects/sync/#automatic-lock-and-sync), so
mutation probes use the already-synced Python directly.
