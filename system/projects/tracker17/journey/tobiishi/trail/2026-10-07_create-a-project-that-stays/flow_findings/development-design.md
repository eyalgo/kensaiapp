Where: `change_design.md §5 Test Additions`, rows D `test_routes.py` and E `test_first_project.py`. Add a rule-implied maximum case: a duplicate name refusal and a failed save, each with a 200-character name and a 4,000-character description of non-ASCII characters, with the page opening and both values kept. The design's only mention of the bound is the stdlib listener's own 65,536 limit, which it never states or checks.
- **[non-blocking · change-local · divergence-record]** A load-bearing behaviour has no entry in the divergence record. "Answer an undecodable body with 400 and an empty body" appears only in the §4 Code Strategy row for `web/` form values. The sibling decisions (403 for a refused request, 404 for an unknown address, both with empty bodies) are each recorded under Architect Review Notes with their reason; this one is not, and no spec rule or UXD/CONTENT entry gives it. Where: `change_design.md §4` (D — form values) vs `§ Architect Review Notes`. Add the entry with its reason.
- **[non-blocking · change-local · coverage]** The end-to-end suite needs a Chromium binary, and the design never says how it arrives. `docs/SDD.md` RT-4 says setting up the suite is the one network step, "to fetch the test dependencies and the browser the end-to-end tests drive". The design builds the lock from a fresh `venv` and freezes it (§4 F — root files), which installs only the Python package. CP-29 requires `pytest tests/e2e/` to exit 0, and `project.md` has `Setup command: none`. The spec leaves the README untouched, so the browser step has no home in the design. Where: `change_design.md §3 Sub-job F` and `§4 F`. State where the browser install step lives, or record that it is deferred to the README station with the reason, so the plan does not invent it.
- **[non-blocking · change-local · coverage]** CP-5 asks for a test that `data/` is ignored "after a project is created". The only row is `git check-ignore -q data/tracker.json` in `tests/integration/test_start.py`, which holds whether or not any project has been created. Where: `change_design.md §5`, row E `test_start.py`. The e2e row `test_first_project.py` creates a project and could carry the `git status --short` check the spec's Examples name.
