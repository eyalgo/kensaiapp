# 宿場 Shukuba — kensaiapp's router station

*The **instance**-level station: the coordination point for when several projects are all pushing on
**one thing**. A **router**, not a walked station — it names the shared cross-project thing, its
cross-project reached-when, and which project is currently active; the projects do the walking. Sibling
to the 道 Michi declaration (`system/michi.md`) and the seedbed (`system/nemawashi/`), directly under
`system/`. Shukuba exists at both levels, as two different kinds — each project walks its own in
`journey/` (`kensaiapp_structure.md` §2); this one coordinates across them.*

---

**This is a folder, not a file.** There is exactly **one** active router station — its own file,
`<YYYY-MM-DD>_<slug>.md`, holding the station in full: the shared thing the contributing projects are
pushing on, its **cross-project reached-when** — a real gate, met when every contributing project has
reached its local station on the shared thing and the thing is proven, not a restatement of the last
project's — and a `currently active: <project>` pointer naming whose turn it is. The pointer is
**hand-maintained by the Principal PM**, whose posture owns this router. One file, so a finished station
is moved whole.

**A router coordinates; it is never walked.** A *project* Shukuba is walked — opened from its Nemawashi
checklist, crossed by 飛び石 Tobiishi, reached. This station is **never crossed by Tobiishi**: the
contributing projects do the crossing in their own journeys, each project's Shukuba pointing up to this
one while the router points down at whichever project is currently active. It is a coordination baton
along a Way, not a terminus — the instance still has no 上がり Agari and steers by its Michi.

**Lifecycle.** Open a router station when several projects converge on one thing. When its cross-project
reached-when is met, **move the station file to `trail/` — by hand today, because no skill moves it
yet.** Never strike a station through. `system/shukuba/trail/` is the record of coordinated things that
finished.
