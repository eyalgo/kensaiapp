# 根回し Nemawashi seed — brackenway is listed in the two app stores

## What it is

Listing is a set of acts the owner performs in each store's console; nothing here is built.

## Source

The owner, when the project was set up.

## Stations — dynamic checklist

- [ ] developer-accounts — the owner opens a developer account in each store
- [ ] store-screenshots — the owner uploads screenshots to each store
- [ ] privacy-labels — the owner fills in each store's privacy form
- [ ] first-submission — the owner submits to each store
- [ ] review-answers — the owner answers each store's review questions
- [ ] release — the owner releases in each store
