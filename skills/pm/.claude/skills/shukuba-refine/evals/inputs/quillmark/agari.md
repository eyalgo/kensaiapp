# 上がり Agari — quillmark's "done"

quillmark lets a writer submit a manuscript to the press and know at once whether it meets the press's
rules.

**Reached when** all hold:

1. A writer submits a manuscript as one file and gets a yes or a reason within a minute.
2. Every rule the press states is checked at submission, and each refusal names the rule.
3. The press's editors see every accepted submission in one list.
