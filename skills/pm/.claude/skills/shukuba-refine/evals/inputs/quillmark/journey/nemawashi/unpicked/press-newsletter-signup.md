# 根回し Nemawashi seed — a writer can sign up for the press's newsletter

## What it is

On the confirmation page a writer can tick a box to get the press's monthly newsletter. Done: a ticked
box adds the writer's email to the newsletter list.

## Source

The press's editor asked the owner for it.

## Stations — dynamic checklist

- [ ] signup-box — the confirmation page offers the box
- [ ] list-receives-the-email — a ticked box adds the email to the list
