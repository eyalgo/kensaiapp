# 上がり Agari — tidewell's "done"

tidewell sends a harbour user a message before each high and low tide at the harbour they follow. It
is done when a user can rely on it without checking a tide table themselves.

**Reached when** all hold:

1. Every subscribed user gets an alert 30 minutes before each tide at their harbour, on 99% of days,
   measured over 30 days.
2. Every alert states the tide in the harbour's local time.
3. A user can pause, resume and stop alerts with one message each.
