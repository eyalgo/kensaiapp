# stations-blind-review — Claude intelligence

The model and effort a run of this skill goes at on Claude — the file `<CORE>/launchers/skill/launcher.sh` reads.

**Model:** claude-opus-5-5
**Effort:** high

## Why

The review's output is acted on as written: the PM fixes the route from it, and a finding it misses is
walked. The method was measured on Opus at high effort, three runs graded blind against a known set of
a route's defects, and it held on every run. No other tier has been measured.
