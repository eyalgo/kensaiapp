# 根回し Nemawashi seed — every page carries the headers its own view asks for

## What it is

Pages take their header set from the view that renders them, as NFDR QC-4 asks, so a later view can
carry a header of its own without the edge learning about it.

## Source

NFDR QC-4 (`docs/nfdr.md`), cut by the Principal PM.

## Stations — dynamic checklist

- [ ] page-headers-come-from-the-renderer — the header set leaves the edge and travels with the view
- [ ] a-view-marks-itself-not-storable — the first view to carry a header of its own

## Out (later / elsewhere)
