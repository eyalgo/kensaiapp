# development-design — Claude intelligence

The model and effort a run of this skill goes at on Claude — the file `<CORE>/launchers/skill/launcher.sh` reads.

**Model:** claude-opus-5-5
**Effort:** high

## Why

Architectural blast-radius analysis, decomposition into sub-jobs, interface contracts, and code strategy are load-bearing design tasks; Opus fits agentic coding and knowledge work at $4/$20, avoiding Fable’s $10/$50 premium for a change-scoped run.
