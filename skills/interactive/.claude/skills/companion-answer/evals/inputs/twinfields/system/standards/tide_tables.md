# Tide tables standard — Twinfields

**Status:** Draft — open issues outstanding

## 1. What this standard covers

Which tidal predictions Twinfields publishes, from what source, and how a correction is issued.

## 2. Source

The national predictions for the nearest standard port, with the local secondary-port corrections
applied.

## 3. Corrections

A correction is issued when an observed height departs from prediction by more than the posted
tolerance. The tolerance is not yet fixed.
