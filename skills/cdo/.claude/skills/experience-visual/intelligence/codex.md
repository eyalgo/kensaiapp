# experience-visual — Codex intelligence

The model and effort a run of this skill goes at on Codex — the file `<CORE>/launchers/skill/launcher.sh` reads.

**Model:** gpt-6.1-sol
**Effort:** high

## Why

The visual fence and direction bind every product under the instance, and the run parks what it cannot settle rather than asking, so its calls stand until the owner reads them. That needs high reasoning effort. The work is one instance-wide pass of the same kind as `product-design`'s single product, so it takes the same model at the same effort.
