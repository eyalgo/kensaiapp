# deepwell — Claude Code instance

## What this is about

This is **deepwell** — the instance that builds and maintains the replication packages the lab
publishes alongside every paper.

A replication package is the deposit a reader downloads to re-run the work: the data, the code that
produced each figure and each number, and the documents that say how to run it and what came out.
deepwell holds all four.

The documents written here leave with the package. Their reader is a referee or a stranger who was
not in the room, has no access to the lab, and has no way to ask a follow-up question — they either
reproduce the result from what is written, or they file a correction request. Once the paper is
accepted the deposit is frozen, so a sentence that was almost right stays almost right for good.

None beyond the user-global rules.
