# deepwell — domain doctrine

What binds the lab's deposits, and where it comes from.

## The journal's replication policy binds every deposit

The lab publishes in journals that require a replication deposit, and the policy is not ours to
soften:

- **Every reported number is reproducible from the deposited artifacts.** A number in the text that
  no deposited script produces is a correction notice, not a typo.
- **A figure names the script that drew it.** The caption is not enough; the deposit must let a
  reader go from the figure to the code without searching.
- **The deposit is frozen at acceptance.** After that it is amended only through the journal's own
  correction process, in public.

## Claims about results

- A result that has not been re-run since the data last changed is not reported as a result.
- Where a check was not performed, the deposit says so. An absent check is never left to be inferred
  from a silence.

## Data handling

- Human-subject data is deposited only in the de-identified form the ethics approval names.
- Raw collection instruments are deposited whole, including the ones that produced nothing.
