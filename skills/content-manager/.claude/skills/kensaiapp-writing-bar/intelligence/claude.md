# kensaiapp-writing-bar — Claude intelligence

The model and effort a run of this skill goes at on Claude — the file `<CORE>/launchers/skill/launcher.sh` reads.

**Model:** claude-opus-5-5
**Effort:** high

## Why

The writing bar is one document that every later document authored in the instance is held to, as written. The run is non-interactive: it settles what it can on its own authority and parks the rest for the owner, so a weak call binds before anyone reads it. That is senior authoring, which earns Opus at high effort. It is a single bounded document, not a long-horizon run, so it does not earn Fable.
