# changelog-line — Claude intelligence

The model and effort a run of this skill goes at on Claude — the file `<CORE>/launchers/skill/launcher.sh` reads.

**Model:** claude-opus-5-5
**Effort:** medium

## Why

Opus, because the run makes two judgements that nothing downstream re-reads as authored: whether the change alters what a user of a fresh clone installs, runs, types or reads, and whether a what-left want is wholly built. A wrong removal deletes a record of work still owed, and the merge carries that deletion to `main`. Medium effort, because the work is bounded to the changelogs of the product paths the change touches and one what-left file, and the evidence is a branch the run reads in full: the diff, the commits and a want's text. The step runs on every change, so a higher effort would be spent on the many changes that earn no entry. Chosen with the test that places this skill among the chain's judgement steps (`tools/test_intelligence.py`, the Claude inventory).
